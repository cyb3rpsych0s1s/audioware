Scriptable object base with separate value-holder storage for scripted fields.

SDK: IScriptable.

Returns the separate script value-holder base, which may be null.

Use this container for holder-relative properties, not native object-relative properties. It does not keep the object or holder alive.

pub fn set_native_type(&mut self, class: &Class)

Replaces the native class metadata pointer without changing object layout. The class metadata must remain valid for the lifetime of this object.

Source

pub fn clone_native_base(&self) -> Self

Creates a fresh native base, retaining type metadata but not object identity.

This deliberately does not copy scripted fields or the embedded weak handle. Native Rust classes can use this in a manual Clone implementation to copy their own fields without duplicating engine-owned base state. Scripted objects must be copied through engine RTTI instead.
