Struct StackFrame 

Source 
pub struct StackFrame(/* private fields */);
Expand description

Borrowed script stack frame. Reading arguments advances bytecode state; restore it before forwarding a hooked call.

SDK: CStackFrame.

pub unsafe fn instr_at<I: Instr>(&self, offset: isize) -> Option<&I>

Reads operands of I at a byte offset from the current bytecode pointer.

Returns None if there is no bytecode or the opcode does not match I.

§Safety

The offset must point to a readable opcode within the current bytecode allocation. If it matches, the following bytes must be valid operands of I and remain valid and unchanged for the returned borrow.

Source

pub unsafe fn step(&mut self)

Advances the bytecode pointer by one opcode byte, not a whole instruction.

§Safety

The current pointer and the advanced pointer must lie within the same valid bytecode allocation (or one byte past its end).

Source

pub unsafe fn get_arg<T>(&mut self) -> T
where T: FromRepr,

Evaluates and consumes the next argument, advancing the frame’s bytecode state.

§Safety

The frame must point to a valid next argument expression, and T must match its type. Any engine systems needed to evaluate it must be initialized. Restore the argument state before forwarding a hooked call.

Source

pub fn args_state(&self) -> StackArgsState

Captures bytecode and argument-data pointers for restore_args.

Capture before reading any arguments; the argument index is not saved.

Source

pub unsafe fn restore_args(&mut self, state: StackArgsState)

Restores saved argument pointers and resets the argument index to zero.

This does not undo side effects of evaluating argument expressions.

§Safety

The snapshot must come from this frame before any arguments were read, and its pointers must still be valid. Read the full argument list and restore it before forwarding the frame to the original game function.

§Example
// For a hooked function taking exactly one CName argument:
unsafe fn inspect(frame: &mut StackFrame) {
    let state = frame.args_state();
    let name: CName = unsafe { frame.get_arg() };
    // Inspect `name`, then restore before forwarding the call.
    unsafe { frame.restore_args(state) };
}
