Source
Expand description

Rust wrappers for engine types. Engine-backed allocation, RTTI, and singleton access require a live game runtime.

SDK: SDK types. SDK-compatible values, containers, and borrowed engine views.

Engine-backed allocation and singleton access require initialized game systems.
