Struct Ref 

Source 
pub struct Ref<T: ScriptClass>(/* private fields */);
Expand description

A strong, reference-counted handle to a class instance (ref<T> in REDscript).

Cloning shares the same instance rather than copying its fields. A default handle is null; a non-null handle keeps its instance alive until the last strong handle is dropped. Use WeakRef to refer to an instance without keeping it alive.

Unlike ScriptRef, this owns a share of the instance. Field access is unsafe because the engine and other handles may access the same data.

SDK: Handle.

pub fn downgrade(self) -> WeakRef<T>

Consumes this strong handle and returns a weak handle to the same instance.

If this was the last strong handle, the instance is destroyed and the returned weak handle cannot be upgraded. Clone first to retain ownership.
