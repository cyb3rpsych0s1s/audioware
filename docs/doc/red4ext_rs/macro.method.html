Macro method 

Source 
macro_rules! method {
    ($name:literal, $ty:ident::$id:ident $($mods:ident)*) => { ... };
    (event $name:literal, $ty:ident::$id:ident $($mods:ident)*) => { ... };
    (final $name:literal, $ty:ident::$id:ident $($mods:ident)*) => { ... };
}
Expand description

Creates metadata for an instance method on a native ScriptClass. The method takes &self; use interior mutability for field changes. Prefix the name with event or final to set the corresponding method flag. Scripted field layouts cannot be used as native instance headers.

ⓘ
use red4ext_rs::{ScriptClass, class_kind, method};
struct Fields;
unsafe impl ScriptClass for Fields {
    type Kind = class_kind::Scripted;
    const NAME: &'static str = "Fields";
}
impl Fields { fn value(&self) -> i32 { 1 } }
let _ = method!(c"Value", Fields::value);

Usually used in conjunction with the methods! macro.
