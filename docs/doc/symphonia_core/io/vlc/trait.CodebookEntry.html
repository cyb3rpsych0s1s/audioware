Expand description

The CodebookEntry trait describes an entry in a codebook.

This trait should be implemented by a zero-sized marker struct. When instantiating a Codebook, the marker struct implementing CodebookEntry is supplied as the type argument.

Dyn Compatibility§

In older versions of Rust, dyn compatibility was called "object safety".
