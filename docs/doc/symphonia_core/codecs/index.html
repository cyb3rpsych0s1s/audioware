The codec module and its sub-modules provides traits and supporting infrastructure to implement audio, video, and subtitle decoders.

§Nomenclature

  • A codec ID refers to a unique identifier for a specific codec.
  • A codec type refers to the type of media the codec is encoding: audio, video, subtitles, etc.
  • Codec parameters refers to a set of parameters common to a particular codec type (e.g., audio sample rate).
